## What landed (production, single code path — GR5)

- **CO-1 additive committed strength** (`combat.py`). `resolve_battle` takes `committed_attacker` / `committed_defender` (default `0.0` → every solo battle and existing caller is byte-identical); `_calculate_effective_strength` adds the already-effective committed mass after the lead's own multipliers. `combat_executor._execute_attack` computes both sides' committed strength on the coordinated path and passes them in. Symmetric for a reinforced defender.
- **CO-1b personality- & relationship-scaled contribution** (`combat_executor._committed_reinforcement_strength`). Each reinforcer contributes `α · strength · get_combat_effectiveness() · get_attack_modifier(1.0, consume=False) · rel_factor`. The attack modifier is **read** with a new `consume=False` path on `Marshal.get_attack_modifier` (GR1 single source, no one-time bonus spent scoring a reinforcer); `rel_factor` is the MC-3 `_RELATIONSHIP_SCALING` (×0.0 hostile … ×1.5 devoted) with the same Jealousy-v3.2 withholding the coordination path uses (aggressive grievance → hard 0.0).
- **CO-2 odds band = committed force** (`objection_v2.inferred_attack_effective_ratio` / `inferred_attack_odds_band` gain `committed_attacker=0.0`; `_build_muster_preview` sums the WILL-JOIN reinforcers' contribution and passes it). The CR-5 gate's lead-only read is unchanged.
- **CO-5 single-source survivor count** (`combat_executor._reconcile_report_survivors`, called after distribution). The battle report's `casualty_summary` and the event now read ONE canonical post-battle strength — the two-truths bug is gone (M4 100%).
