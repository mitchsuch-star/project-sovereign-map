## The method
A third blind author — an agent with no access to the repository, given only what a player sees on the 1805 boot screen (the roster and where it stands, the two enemies in sight, the neighbouring provinces, the courts and their states, the things the game's own screens say a player can do) and the ONE judge's family names for `intended.action` — wrote **300 orders**, no questions, in deliberately varied registers (terse, chatty, formal, sloppy with typos, questions-that-order, a reason tail, an aside, a condition, a compound, epithets, pronouns, the name after the verb), with **31 lines meant to be refused**. The file was written in one call; when it came back one row short the same author appended one, still blind. Each line ran on a FRESH 1805 boot board through the real `POST /command`, keyless (`LLM_MODE=mock`) and keyed (`anthropic`, the 0.7 gate's escalation live — 64 of 300 lines reached the model), read by the ONE judge (`tools/_score_probes.py`, unchanged), and every row carries its parse trace.
