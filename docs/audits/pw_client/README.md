# Row PW "Plain Words" — the blind reading (November 18, 2026)

The frames are the real client at the first player's own setup (Interface Scale 1.8 on a 5120 x 1377
window: a logical view of 2844 x 765), shot by the instrument (`tools/dd_b_play.py`,
`DD_B_UI_SCALE=1.8 DD_B_WINDOW=5120x1377`): **A** the war card on the map · **B** the peace table after one
press of "Offer them more" · **D** the Cabinet's page for an enemy · **E** the report after End Turn ·
**F** a battle with no winner yet.

**The bar, written before any frame was read:** three fresh readers (Sonnet) who have never seen the game
are shown only the five frames and asked six questions; the bar is met only if EVERY reader answers EVERY
question correctly by the key. A reader's "I cannot tell" on what the key asks is a miss.
