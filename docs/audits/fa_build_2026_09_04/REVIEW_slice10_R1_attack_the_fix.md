### [P2 → NARROWED] FA-N45 keys the stored treaty harshness to the proposal's ADDRESSEE, so an AI court that sues for peace and dismembers itself records harshness 0.0 and DD8-4 never fires

**Seam:** `backend/models/world_state.py` :: `WorldState._ratify_treaty — `"harshness": burden_on_nation(treaty_clauses, target_nation)` (helper: diplomatic_templates.burden_on_nation)`

**Evidence**

`burden_on_nation` selects `clause["from"] == nation`, and the nation passed is `target_nation` — the proposal's addressee (`proposal.get("target_nation") or proposal.get("target")`), not the party that gave things up. The row's own docstring says the number wanted is "was this treaty harsh on the party who signed it away"; those two coincide only when the winner is the proposer. `_ratify_treaty` builds clauses so that demands carry `from = target_nation` but sweeteners carry `from = proposer` — an AI suing for peace concedes through SWEETENERS. Note the sibling call at the separate-peace penalty gets this right (`penalty_target = target_nation if proposer == self.player_nation else proposer`); only the stored record uses the bare addressee. Probe (scratchpad/agent_probes/p9_burden_direction.py, 1805 boot, two `_ratify_treaty` calls): ARM A, France proposes and demands 900 gold + Bohemia of Austria → clauses `[{gold_lump, from Austria, to France, 900},{territory_cede, from Austria, to France, [Bohemia]}]`, STORED harshness 1.0, DD8-4 fires. ARM B, Austria proposes and offers the same 900 gold + Bohemia as sweeteners → BYTE-IDENTICAL clause list, STORED harshness 0.0, DD8-4 does not fire; `burden_on_nation(clauses, "Austria")` is 1.0, and the pre-slice value (both sides summed) was 1.0 in both arms. The consumer is `diplomacy.py` in the acceptance formula: `if treaty.get("harshness", 0) > 0.3: harshness_bonus = -5  # harsh history breeds resentment`.

**Failure scenario**

Austria, losing, sues France for peace and concedes Bohemia and 900 gold. The treaty record for the France|Austria pair stores harshness 0.0. Every later proposal between that pair is scored as if the two courts had never signed anything punitive — the DD8-4 escalating-harshness memory the slice's own comment says it exists to un-break is now permanently off for the entire class of AI-initiated concession peaces, which is the commonest way a beaten AI leaves a war. The identical dismemberment recorded 1.0 when France proposed it, so the pair's political memory depends on who drafted the paper rather than who paid.

**Suggested fix**

Pass the party that actually bears the package, not the addressee. Either compute `max(burden_on_nation(clauses, proposer), burden_on_nation(clauses, target_nation))` — the burden on whichever side gave more, which is what "was this treaty harsh" means for a pair-scoped memory — or mirror the separate-peace arm and resolve the bearing party explicitly. Pin it with the p9 two-arm test: identical clause lists must store identical harshness whichever side is named proposer.
